## ProjectK.ProbeAndBadges

Для пластових додатків немає жодної бібліотеки вмілостей, яка допомогла б розробникам вбудувати
повну збірку в свої застосунки, і немає єдиного джерела правди, що оновлювалося б. Тому написано
інструмент PlastBadgesParser, що збирає всі вмілості з бібліотеки вмілостей на глобальному сайті
Пласту, а поверх нього — бібліотеку `ProjectK.ProbeAndBadges` з усіма вмілостями і пробами УПЮ
(1 і 2) у зручному JSON та інструментом для підключення у .NET-застосунок як статичних файлів.

> When assets extraction is enabled and zip source path is available, the library extracts images
> to a local snapshot directory and exposes state via IBadgesAssetsStore.

## Закрите бета-тестування

Проєкт перейшов у стадію `beta` — великий майлстоун. Готується закрите бета-тестування; саме для
нього зроблено список очікування із запрошеннями. Планується 5 куренів, у кожному до 10 активних
користувачів (це не обмежує кількість юнаків чи гуртків у системі). Для ЗБТ рекомендується
активувати акаунти КВ.

## Пошта

Для листів залучено Resend: запрошення для ЗБТ і системні листи.

## Деплой в Azure

Задеплоєно фронтенд, бекенд, базу і blob storage. Уся інфраструктура на free-tier — сервери
обмежені й не готові до повного релізу, але для ЗБТ достатньо. Для масштабування потрібні
додаткові кошти — дискусійне питання для життя продукту в хмарі.

**Поточна ціль — повністю безкоштовне користування для всіх. Ніякої плати. 0 грн.** Але треба
думати про зовнішні кошти, спонсорство чи донати на інфраструктуру.

## Мураха

`v0.10.0-beta` переступила ще один поріг і отримала кодову назву **«Мураха»** (Ant).

### Профілі користувачів

Додано профілі користувачів: свій можна редагувати, чужі — ні. Тепер є звʼязок `member ↔ user`.

### Upsert-member

Додано функцію створити доступ користувачу при створенні учасника. Планується додавання
користувача до наявного учасника.

### Стиснення зображень

Додано компресію фото учасників (`SixLabors.ImageSharp`), що значно оптимізує місце у blob storage.
