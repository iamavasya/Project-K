Цей девлог особливий: впродовж першого спринту задано вектор проєкту, визначено цільову аудиторію,
накинуто стек технологій.

## Технічна частина

Для внутрішньої розробки проєкт отримав нову назву «Project K2»: перша частина припинила
підтримку, але лишилась відкритою на GitHub.

1. Проєкт перейшов з монолітної архітектури на мікросервісну.
2. Налаштовано базову JWT-автентифікацію через API Gateway.
3. Усі сервіси контейнеризовано в Docker для локальної розробки: якщо один сервіс впаде, решта
   застосунку працюватиме.
4. Спроєктовано MVP-діаграму бази даних.
5. Створено NuGet-пакет `ProjectK2.Shared` у GitHub Packages (1.0.9.1) — спільні сутності й моделі
   між сервісами.
6. Додано healthcheck-и мікросервісів для гейтвею: раз на 10 секунд перевірка й лог.
7. Додано брокер RabbitMQ з тестовим консюмером і топіком на гейтвеї.
