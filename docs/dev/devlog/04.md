## Дорога до v0.4

Нових релізів не було, окрім патчу 3.1, бо йде велика робота над новим модулем.

У додаток додано автентифікацію (JWT) та авторизацію; доступ до ресурсів іде через ролі та їхні
політики. На той момент додаток поділено між чотирма ролями — Admin, Manager, Mentor та User (де
Manager, Mentor та User — внутрішні ролі, привʼязані до куреня; Admin не привʼязаний до жодного куреня
і є зовнішньою роллю).

Ціль v0.4 — business-flow для адмінів: створити курінь з першим менеджером. Бекенд-логіка вже є,
ведеться робота над UI.

### Що вже реалізовано

1. **Login.** Базовий UI для входу в систему.
2. **Toolbar та Sidebar.** На тулбарі дві кнопки — сайдбар зліва і вихід справа. З сайдбару можна
   перейти на вкладки поточного куреня, побачити свій акаунт і зробити налаштування.
3. **Оновлений режим адміна.** Admin не привʼязаний до куреня, тож додано тимчасове входження в
   курінь через адмін-панель; на тулбарі зʼявляється кнопка виходу з куреня назад у панель.
   Після логіну User/Mentor/Manager потрапляють у свій курінь без доступу до інших; Admin — в
   адмін-панель, де обирає, в який курінь зайти.
4. **Role pills.** Внизу сайдбару — плашка з поточною роллю користувача.
5. **Guards та захист ресурсів.** Оновлені гуарди й захищені ресурси, щоб користувач одного куреня
   не міг переглядати ресурси іншого.
6. **Бекенд.** Контролери й сервіси під JWT, сутності в БД; .NET піднято до 9.0.

## Що далі?

Більша частина шляху до v0.4 пройдена. У четверте оновлення планується UI для адмінів і кілька
оновлень UI куреня. Реєстрація першого користувача в курінь — першочергове завдання версії.
