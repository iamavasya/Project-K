*10 жовтня 2025.* Оригінал зі скриншотами — [у Notion](https://iamavasya.notion.site/27d7512d9a7280d6b7b3ec923e35cf5a).

Релізи після DevLog #4: `v0.4.0-alpha.1`.

## Реліз v0.4.0

Як і анонсовано в [DevLog #4](/dev/devlog/04/), четверта версія відзначається JWT-автентифікацією
та авторизацією.

### Member List

Новий UI-компонент зі списком усіх учасників. Працює і як список куреня, і як список гуртка.

### User List

Компонент для адмінів, доступний з адмін-панелі: усі користувачі системи. Редагування ще не
реалізовано — це функції наступних версій.

### Транзакція першого менеджера

Ключова функція четвертої версії. Тепер при створенні куреня адміном задається пошта майбутнього
менеджера; йому створюються тимчасові дані, які він змінить після реєстрації. Кнопка «Create +»
запускає на бекенді один ланцюжок:

1. створити новий курінь;
2. зареєструвати користувача з роллю Manager і додати його в курінь;
3. створити учасника куреня і звʼязати його з користувачем;
4. зберегти зміни, закомітити транзакцію.

## Інші зміни

- Перейменовано частину фронтенд-компонентів для читабельності.
- Мігровано з SCSS на CSS, додано Tailwind CSS.
- Оновлено вразливі пакети до стабільних версій.

Очікується в патчах v0.4.x: нові поля `Member` (ступінь, діловодство, адреса), заміна старого
списку гуртка на member-list, фікс нествореного учасника менеджера в транзакції, фікс видалення
учасників при видаленні гуртка чи куреня.

## Що далі?

Патч 4.1 з фіксами, новими полями й чисткою коду. Далі версія 0.5: зручне планування таборових дат,
система точкування, нові поля учасника, збереження та відображення проводу.
