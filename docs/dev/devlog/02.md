## What's changed?

### Pre-release version

Pre-release `v0.2.0-alpha.1` is here.

### Frontend

1. Added new components — member-panel, member-card and upsert-member:
   - member-panel displays all the members in a certain group;
   - member-card displays personal info of a member;
   - upsert-member works as a component for creating or updating a member on demand.
2. Added external library `ngx-image-cropper` to crop the uploaded photos.
3. Added support of profile photos for members.
4. Added validation for the upsert-member form.

### Backend

1. Added new entity Member with CQRS pattern on the business layer.
2. Added integration with Azure Blob Storage (for now with local Azurite). As a result, a local
   blob storage is running, which gives an opportunity to store members' profile photos and other
   files (blobs) in the future.

### Other updates

1. Writing internal documentation — how to start up the project, roadmap, tech stack, business
   rules, architecture design, etc. For the future expansion of the dev team or communication with
   stakeholders or clients.
2. Integration and unit test coverage both on front and backend sides.
3. Code cleaning and refactoring using SonarQube and eslint.
