*15 серпня 2025.* Оригінал зі скриншотами — [у Notion](https://iamavasya.notion.site/2547512d9a72804b98e6c110b4e62ab1).

Очистка репозиторію.

## Архітектура

- Повністю переписано **бекенд** з нуля: моноліт з частковою модульністю.
- Реалізовано **CRUD-операції** для кількох основних сутностей.
- Зроблено **базовий фронтенд** для початкової роботи та дебагу — CRUD над цими сутностями.

## Features

- Універсальна форма редагування для роботи з різними сутностями.
- Повідомлення на фронтенді, коли список сутностей порожній.

## Технічні покращення

- Увесь код покрито юніт- та інтеграційними тестами.
- Впроваджено CQRS у бекенді.
- Додано мапінг-профілі, CORS-політику, Swagger UI для документації API.
- Налаштовано початковий CI у GitHub Actions для фронтенду й бекенду: тести, лінтинг, перевірка
  якості коду.

## Стек на той момент

- Frontend: Angular 20, PrimeNG 20, Karma/Jasmine.
- Backend: ASP.NET Core (.NET 8), SQL Server + EF Core, xUnit.
