Проби, вмілості й відзначення УПЮ — це юнацький вишкіл. Старшим пластунам (УСП) і сеніорам (УПС)
вони не потрібні, тож Лілейка їх цим людям не показує. Що саме бачить людина, залежить від її
**особистої гілки**.

## Особиста гілка людини

Лілейка визначає гілку за найвищим **пластовим ступенем** людини:

- є ступінь старшого пластуна — людина в **УСП**;
- є будь-який сеніорський ступінь — людина в **УПС**;
- інакше — гілка куреня, у якому вона зараз, тобто здебільшого **УПЮ**.

Ступені вписують у картці: **«Редагувати»** → **«Пластові ступені»**. Перемикачі **УПЮ / УСП / УПС**
там лише відкривають потрібні поля дат:

| Перемикач | Поля |
|---|---|
| завжди | Дата вступу до Пласту, Дата здобуття прихильника, Дата заприсяження |
| **УПЮ** | Дата здобуття розвідувача, скоба / вірлиці, гетьманського скоба / вірлиці |
| **УСП** | Дата переходу в УСП |
| **УПС** | Дата переходу в УПС, пл. сен. праці, пл. сен. довірʼя, пл. сен. керівництва |

Вимкнути перемикач — означає стерти дати цієї гілки.

## Що змінюється для УСП і УПС

На картці людини з УСП чи УПС немає плиток **«Здобуті вмілості»**, **«Проба»** і **«Відзначення
УПЮ»**. Пройдена проба лишається видно, але лише для перегляду — без підписів. На
[головній](/user/features/dashboard/) у такої людини немає плиток проби й вмілостей, а «Мої бали»
рахують лише юнацтво УПЮ.

Плитка **«Впорядництво»** не залежить від гілки: вона є в кожного, хто має роль у КВ або закріплений
за гуртком.

## Гілка куреня

Гілку куреня видно тегом біля назви на сторінці куреня, у плитці «Членства», у перемикачі куренів і
в заголовку реєстру. У курені УСП чи УПС немає пункту **«Модерація вмілостей»**, а сторінка
модерації показує «Тут такого немає».

Реєстр куреня підлаштовує колонки дат і таблицю **«Чисельність за ступенями»** під гілку: для УПЮ —
до гетьманського скоба, для УСП додається старший пластун, для УПС — уся драбина ступенів.

:::caution[Змінити гілку куреня поки не можна]
Кожен новий курінь у Лілейці створюється як УПЮ, і в інтерфейсі гілку куреня поки не змінити.
Якщо ваш курінь — УСП чи УПС, напиши через [«Повідомити про проблему»](/user/report-problem/), і
гілку виставлять вручну. Картки людей від цього не залежать: їх визначають особисті ступені.
:::
