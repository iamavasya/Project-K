Усе, що стосується тебе, приходить у **дзвіночок** у верхній панелі. Число на ньому — скільки
непрочитаного. Натисни дзвіночок, відкриється список **«Сповіщення»**; клік по сповіщенню веде
на сторінку, про яку воно: картку, пробу, задачу чи подію.

## Що приходить

- **Проба і вмілості:** твою вмілість подано на розгляд або розглянуто; для впорядника — юнак
  подав вмілість.
- **Відзначення й перестороги:** тобі виписали відзначення чи винесли пересторогу; для проводу —
  подано відзначення на розгляд.
- **Верифікація:** твій профіль верифіковано або дані змінилися після верифікації.
- **Провід:** твоє діловодство змінилось.
- **Календар і задачі:** тобі призначили подію чи задачу, її змінили, перевели в інший стан або
  видалили.
- **Адміністратору:** нова заявка куреня на розгляд.

## Що приходить листом

На пошту йдуть лише запрошення в акаунт, відновлення пароля, зміна пошти і заявки для
адміністратора. Решта живе в застосунку, тож дзвіночок варто перевіряти.
