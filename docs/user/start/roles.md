У Лілейці немає окремих «прав», які хтось видає вручну. Є **ролі** (діловодства) — ті самі, що в
курені: Звʼязковий, впорядник, курінний, скарбник, гуртковий і так далі. Провід записує, хто яку
роль тримає, і система сама виводить, що людині можна. Змінилась роль — змінились права, щойно
людина наступного разу відкриє Лілейку.

## Хто що може

«Гуртковий провід» — гуртковий і решта проводу гуртка (скарбник, суддя, писар гуртка…).
«Курінний провід» — курінний і решта проводу куреня. Де права залежать від конкретної ролі, це
сказано в клітинці.

| Що | Юнак | Гуртковий провід | Впорядник | Курінний провід | Звʼязковий | Адміністратор |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| свою картку, пробу, вмілості; свій профіль і акаунт | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| картки людей куреня | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| реєстр куреня | | | ✓ | | ✓ | ✓ |
| редагувати картки інших | | | свій гурток | | ✓ | ✓ |
| додати нову людину | | | у свій гурток | | ✓ | ✓ |
| перевести, вивести, повернути, імпорт складу | | | | | ✓ | ✓ |
| підписувати пробу, підтверджувати вмілості й відзначення | | | свій гурток | | ✓ | ✓ |
| перестороги, верифікація профілю | | | свій гурток | | ✓ | ✓ |
| створювати події й задачі | | ✓ | ✓ | ✓ | ✓ | ✓ |
| змінювати чужі події й задачі | | | свого гуртка | | ✓ | ✓ |
| планування: створювати | | ✓ | ✓ | ✓ | ✓ | ✓ |
| записувати провід | | гуртковий — свій гурток | свої гуртки | курінний — курінь | ✓ | ✓ |
| КВ: додати впорядника, гуртки, передати роль Звʼязкового | | | | | ✓ | ✓ |
| вкладка гуртка | свій баланс | гуртковий і скарбник гуртка | свій гурток, підтверджує | скарбник куреня читає | ✓ | ✓ |
| вкладка куреня | | | | скарбник куреня | ✓ | ✓ |
| точкування: присутність і бали | | гуртковий і суддя гуртка | свій гурток | курінний, суддя куреня | ✓ | ✓ |
| «Точкування КВ», налаштування точкування | | | книга КВ | суддя куреня — налаштування | ✓ | ✓ |
| налаштування куреня, дані куреня, PDF-звіт, гуртки | | | перейменувати свій гурток | | ✓ | ✓ |

Бачити календар, задачі, планування й таблицю точкування може кожен у курені — кожен бачить те, що
стосується його.

**Інструктор** — людина з КВ без закріпленого гуртка. Він має права КВ (планування, події й
задачі, книга КВ), але права «на свої гуртки» в нього нічого не відкривають, поки гуртка немає.

Записуючи провід, людина не може призначити саму себе: курінного призначає Звʼязковий, гурткового —
впорядник гуртка або Звʼязковий.

## Впорядник закріплений за гуртком

Впорядник у Лілейці — той, кого Звʼязковий закріпив за гуртком у плитці **«КВ»** на сторінці
куреня. Одна людина може вести кілька гуртків, у гуртка може бути кілька впорядників. Людина з КВ
без гуртка — **інструктор**.

## Твоя роль унизу бічного меню

Унизу бічного меню видно твою пошту і роль у поточному курені — наприклад «Впорядник» або
«Звʼязковий». Якщо роль у курені не записана, там «Провід куреня», «Гуртковий провід» чи
«Учасник». Колір тегу той самий, що в списках людей.
